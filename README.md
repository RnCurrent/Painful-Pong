# 2-Player Pong in Python

- Basic local 2-player Pong game built using Python and Pygame
- Fun tweaks added

## Setup & Running the Game

Make sure you actually have Pygame installed on your machine

## How to Play
* **Left Side (Player 1):** Use `W` to move up and `S` to move down.
* **Right Side (Player 2):** Use the `Up Arrow` and `Down Arrow` keys.
* **Game Over Screen:** Press `Enter` to play another round
